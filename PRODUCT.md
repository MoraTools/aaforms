## Platform

web

## Users

Automation Anywhere developers who test capture and replay.

## Product Purpose

AA Forms provides static synthetic forms that test capture and replay limits.
A task succeeds only when its submission has the required values.

## Operating Context

Developers capture a form, change its state, then replay the task.
Browser checks verify the fixture. Live AA checks establish recorder behavior.

## Capabilities and Constraints

Use static HTML, CSS and JavaScript. Keep the existing routes, theme controls,
completion progress, reset controls and Back to Main Menu links.
Use synthetic data. A browser check does not establish a live AA failure.

## Brand Commitments

Keep the AA Forms name and its existing blue and gray interface with Arial.
